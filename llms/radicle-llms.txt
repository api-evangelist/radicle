# Radicle

> Radicle is a sovereign, peer-to-peer code collaboration stack built on Git, backed by Electric Capital. Every user runs a node; repositories, issues and patches replicate across the network as cryptographically-signed Collaborative Objects (COBs). Each node can run radicle-httpd, a lightweight HTTP daemon exposing a read-oriented JSON API over the node's storage.

## APIs

- [Radicle HTTP API](https://seed.radicle.xyz/api/v1): radicle-httpd JSON API (apiVersion 6.1.0) — repos, issues, patches, commits, source trees, node info, stats. Public read; key-based session auth for writes on self-hosted nodes.
